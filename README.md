## Principais Insights

### 1. Contrato influencia churn
Clientes com contrato mensal apresentam maior risco de cancelamento.

### 2. Risco no início da jornada
Clientes com até 6 meses têm maior probabilidade de churn.

### 3. Método de pagamento impacta retenção
Electronic check está associado a maior churn.

### 4. Tipo de serviço influencia comportamento
Diferenças entre serviços indicam impacto na retenção.
